# CR7 — Cristiano Ronaldo Tribute

A cinematic tribute website showcasing Cristiano Ronaldo's career journey — from Sporting CP to Al-Nassr — built with React, GSAP, and smooth scroll-driven animations.

## Tech Stack

React 19 · TypeScript · Vite 7 · Tailwind CSS 4 · GSAP ScrollTrigger · Motion

## Getting Started

```bash
npm install
npm run dev
```
